What changes

  • The tool row loses the shortcut suffixes: it reads Shell Claude Codex Copilot Hermes again. Shortcuts live only here, in the Launch group, one row per command.
  • Prose goes. Every row is key then action. Search policy, mouse details and launch semantics are in the README already; the screen keeps only what you press.
  • Groups follow the dashboard's own sections and names: Directory, Tool, Recent. They are headed the way dashboard sections are, not in capitals.

Grid rules (for the ratatui implementation)

  • Same frame as the dashboard: 1–2 column side margin, centred at most 96 columns, the ›_ Launchpad header and a footer on the second-to-last row.
  • Two columns when the content is 72 or more cells wide, with a 4-cell gutter; otherwise one column. The left column holds Launch, Tool and Directory; the right column holds Move, Recent and Launchpad.
  • Key column width = the longest key in the column + 2 cells; Status reuses the left column's width. Alternatives are written Home / End, never with bare spaces. Keys use text, actions muted, group headings accent. Long actions are clipped with …; only the Launch note and configuration errors wrap.
  • Key names are written one way throughout: Ctrl+P, Alt+C, Shift+Tab, arrows as ↑ ↓ ← →, Enter as ↵ as on the dashboard. Configured shortcuts are shown in this form (alt+shift+c → Alt+Shift+C).
  • Status spans both columns under the groups: the search status, then each configuration error in error with a ! in the key column, wrapped.
  • When the content is taller than the space, the body scrolls. A position counter appears on the header row, matching Recent's 1–9 / 10, and the footer adds ↑↓ scroll.
  • With no shortcuts configured, Launch shows one line saying how to add one.
